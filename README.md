# Scratch tile generation experiment

A seeded terrain generator and experimental smoothing pass made in Scratch.

## Open and run

1. Download `Tile Proceedural Genration Example.sb3`.
2. Open the Scratch editor at https://scratch.mit.edu/projects/editor/ (or Scratch Desktop).
3. Choose **File → Load from your computer** and select the `.sb3` file.
4. Click the green flag, then press **Space** to finish generation and render the map.

No dependency installation is needed to edit this project in Scratch. The original uploaded project is preserved unchanged.
